## 코딩 노베이스 비전공자의 바이브코딩 토이 프로젝트입니다.

- 스토리모드: 간단한 카드 튜토리얼 겸 토끼기사의 이야기
- 기사도: 토끼기사의 꿈 속 여정, 로그라이크 덱빌딩

- 세이브: 브라우저 쿠키 등으로 세이브가 구현되어 있는 게 아닙니다. 로그 복사/붙여넣기, 임의 수정하면 적용은 됩니다.
- 세이브 관리 로그를 복사해뒀다가 붙여넣으면 이전에 진행한 내용이 그대로 적용됩니다.


## 개발 방식

- 인간이 하는 일: 스토리 스크립트, 기본 룰, 아이디어, 카드명, 상세 효과 설명, 생체QA, 역으로 해설해달라고 종용하기, 수치 밸런스 겐또 찍기
- 인공지능이 하는 일: 코드 작성, 수치 밸런스 계산, 문장부호오류/버그 찾아내기
