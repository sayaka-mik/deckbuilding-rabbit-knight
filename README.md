### 코딩 노베이스 비전공자의 바이브코딩 토이 프로젝트입니다.
### 게임모드
- 스토리모드: 간단한 카드 튜토리얼 겸 토끼기사의 이야기
- 기사도: 토끼기사의 꿈 속 여정, 로그라이크 덱빌딩
### 세이브 관련
- 브라우저 쿠키 등으로 세이브가 구현되어 있는 게 아닙니다. 로그 복사/붙여넣기, 임의 수정하면 적용은 됩니다.
- 세이브 관리 로그를 복사해뒀다가 붙여넣으면 이전에 진행한 내용이 그대로 적용됩니다.
### 버전 정보
- v1.05 전체 풀: 카드 45종, 버프 8종, 디버프 7종, 의념 5종, 특성 15종, 유물 36종, 일반 적 10종, 엘리트 4종, 보스 5종
- 규칙: 덱 구축 최소 9장~최대 21장, 층마다 일반 엘리트 캠프 중 1개 선택 진행, 랜덤 로테이션, 10층마다 티어업, 9층에선 반드시 캠프 등장 보장, 전투 시 기본 3 드로우, 턴 종료 시 버림, 매턴 활력 3 회복, HP 자동 회복 X, 일반 보상 랜덤 카드, 엘리트 보상 추가 랜덤 유물, 보스 보상 추가 랜덤 특성, 캠프에서 회복과 카드 제거

## 개발 방식
- 인간이 하는 일: 스토리 스크립트, 기본 룰, 아이디어, 카드명, 상세 효과 설명, 생체QA, 역으로 해설해달라고 종용하기, 수치 밸런스 겐또 찍기
- 인공지능이 하는 일: 코드 작성, 수치 밸런스 계산, 문장부호오류/버그 찾아내기
