## 코딩 노베이스 비전공자의 바이브코딩 토이 프로젝트입니다.
### 게임모드
- 스토리모드: 간단한 카드 튜토리얼 겸 토끼기사의 이야기
- 기사도: 토끼기사의 꿈 속 여정, 로그라이크 덱빌딩
- 몽중몽: 기사도 50층 클리어 시 해금. 패배 시 51층으로 돌아옵니다. 노드를 자유롭게 선택하고 원하는 층에서 흩어진 별빛을 수집할 수 있습니다.
### 세이브 관련
- 브라우저 쿠키 등으로 세이브가 구현되어 있는 게 아닙니다. 로그 복사/붙여넣기, 임의 수정을 통해 적용합니다.
- 세이브 관리 로그를 복사해뒀다가 붙여넣으면 이전에 진행한 내용이 그대로 적용됩니다.
- 51층 이후에는 패배 시 51층으로 돌아오지만, 새 게임을 시작하면 초기 로그로 덮어씌워지므로 세이브를 적용하고 싶다면 로그를 미리 복사해두어야 합니다.
### 버전 정보
- v1.15 전체 구성: 카드 49종, 버프 8종, 디버프 7종, 의념 12종, 특성 16종, 유물 40종, 일반 적 10종, 엘리트 4종, 보스 5종, 흩어진 별빛 3종
- 규칙: 덱 구축 카드 최소 9장~최대 21장, 층마다 일반 엘리트 캠프 중 1개 선택 진행, 랜덤 로테이션, 10층마다 적 티어 상승, 9층에선 반드시 캠프 등장 보장, 전투 시 기본 3 드로우, 턴 종료 시 버림, 매턴 활력 3 회복, HP 자동 회복 X, 일반 보상 랜덤 카드, 엘리트 보상 추가 랜덤 유물, 보스 보상 추가 랜덤 특성, 캠프에서 회복과 카드 제거, 호수에서 유물과 특성 제거, 50층 돌파 시 [일반, 엘리트, 캠프, 호수, 보스, 흩어진 별빛]이 매 층마다 상시 개방되며 무한히 층을 오를 수 있음, 몽중몽 세이브 포인트는 별빛 수집 시 갱신됨
### 개발 방식
- 인간이 하는 일: 스토리 스크립트, 기본 룰, 아이디어, 카드명, 상세 효과 설명, 생체QA, 코드 구조 역으로 해설해달라고 종용하기, 수치 밸런스 겐또 찍기, 게임 즐기기
- 인공지능이 하는 일: 코드 작성, 수치 밸런스 계산, 문장부호 오류/숨은 버그 찾아내기
- 사용 모델: Gemini 4 Hydrogen, 4 Neon, 4 Argon(v1.05 이전), 3.0 Pro(v0.65 이전)
